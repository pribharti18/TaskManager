# TaskFlow — Interactive Task Manager

A responsive browser-based task manager built with **HTML5, CSS3, and JavaScript (ES6+)**. Users can organize tasks by priority and category, search and filter in real time, edit items inline, and keep changes saved automatically via `localStorage`.

## Live Demo
- **Live App:** `https://pribharti18.github.io/taskflow-app/`
- **Repository:** `https://github.com/pribharti18/taskflow-app`

## Key Features
- Create, edit, complete, and delete tasks with priority levels and category tags
- Filter tasks by status, search by keyword, and sort entries
- Automatic persistence in the browser using `localStorage`
- Live counters showing active and completed work
- Responsive layout across desktop, tablet, and mobile screens

## Tech Stack
- HTML5
- CSS3 (Flexbox & Grid)
- Vanilla JavaScript (ES6+) & Browser `localStorage`

## How to Run Locally
1. Clone or download this repository.
2. Open `index.html` in any modern web browser (or run it via VS Code Live Server).
